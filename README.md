# Mortiferum-Hotel
Визуальная новелла на движке Ren'Py.
Проект в рамках университетской практики (2023 год).

## Моя роль
- Team Lead: управление кросс-функциональной командой из 4 человек по Scrum.
- Разработчик: написание скриптов, архитектура диалоговой системы.
- Документирование: диаграмма Ганта, концептуальная диаграмма, ТЗ.

## Что было сделано
- Вел полный цикл разработки: от концепции и ТЗ до релиза.
- Контролировал сроки через диаграмму Ганта, визуализировал требования.
- Выступил связующим звеном между сценаристом, дизайнером, разработчиком и тестировщиком.
- Подготовил полный пакет проектной документации.
